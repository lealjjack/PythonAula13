# Python Aula 11

Projeto de estudo do curso de Python, com exemplos básicos de variáveis, impressão na tela e análise de dados.

## Introdução

Este repositório reúne os exercícios da aula 11. Ele usa Python 3.13 e as bibliotecas pandas, numpy e matplotlib, rodando dentro de um ambiente virtual.

### Pré-requisitos

- Python 3.13 instalado
- Git instalado
- VS Code (opcional, mas recomendado para abrir o notebook)

## Conteúdo

- `exemplo.py`: script com variáveis e `print`
- `exemplo2.ipynb`: notebook Jupyter com os exemplos de análise
- `requirements.txt`: lista das bibliotecas usadas

## Execução do projeto

Clone o repositório e entre na pasta:

```
git clone https://github.com/lealjjack/PythonAula13.git
cd PythonAula13
```

Crie e ative o ambiente virtual (no Windows):

```
py -3.13 -m venv .venv
.venv\Scripts\activate
```

Instale as dependências:

```
pip install -r requirements.txt
```

Rode o script:

```
python exemplo.py
```

Para o notebook, abra o `exemplo2.ipynb` no VS Code e selecione o interpretador `.venv`.
